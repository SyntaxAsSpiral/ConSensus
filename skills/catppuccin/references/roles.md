# Roles

Names, not hex. Hex is in [flavors.md](flavors.md). Text on a colored background may leave this table when the text would be illegible.

| Role | Color |
|---|---|
| Background pane | base |
| Secondary panes | crust, mantle |
| Surface elements | surface0, surface1, surface2 |
| Overlays, borders | overlay0, overlay1, overlay2 |
| Body, headline | text |
| Labels | subtext0, subtext1 |
| Subtle | overlay1 |
| On accent | base |
| Links, tags | blue |
| Success | green |
| Warning | yellow |
| Error | red |
| Selection background | overlay2 at 20–30% opacity |
| Cursor | rosewater |
