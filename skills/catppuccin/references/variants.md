# Variants

These are 16-color terminal arrays. They are not the ANSI map in [terminal.md](terminal.md).

| Index | Slot |
|---|---|
| 0 | base |
| 1 | red |
| 2 | green |
| 3 | yellow |
| 4 | blue |
| 5 | mauve |
| 6 | teal |
| 7 | text |
| 8 | surface |
| 9 | peach |
| 10 | green |
| 11 | yellow |
| 12 | sapphire |
| 13 | pink |
| 14 | teal |
| 15 | lavender |

`foreground` and `background` are separate. On rose they are not index 7 and index 0.

## mochafrappe

```json
{
  "name": "catppuccin-mochafrappe",
  "color": ["#303446", "#f38ba8", "#a6e3a1", "#f9e2af", "#89b4fa", "#cba6f7", "#94e2d5", "#cdd6f4", "#414559", "#fab387", "#a6e3a1", "#f9e2af", "#74c7ec", "#f5c2e7", "#94e2d5", "#b4befe"],
  "foreground": "#cdd6f4",
  "background": "#303446"
}
```
