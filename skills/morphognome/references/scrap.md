# Scrap

Scrap on a pattern, not a single instance. A miss that a later act can still correct is not a scrap. A few edge cases do not condemn a shape. Complexity in the material is not complexity in the design.

Tells:

- The same workaround repeating across unrelated parts.
- Many unrelated edge cases that each need their own branch.
- An escape hatch so the form holds together: a cast, an optional that is always set, a type that means anything.
- A lock, or a warning that the state is shared, when the sketch said it was not.
- The user of the form having to know its internal rules.
- Two or more deviations of the same shape.

When you scrap:

1. Re-ground what was built.
2. Redesign as if the new constraints had been there on the first day.
3. Subtract until the new sketch is smaller than the old one. Then it may grow.
4. Return to the double sketch, then the screen, then a new package.
