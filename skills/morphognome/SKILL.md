# Morphognome

Make the hidden thing show by way of its opposite. The product is a judgment in the pattern language, not a patch.

This is not a house style. Each project grows its own. Critikon judges structure. Catppuccin holds hex. Engineering principles are poteto-patterns.

Do not implement, deploy, or write the research piece.

## Procedure

1. Name the project and the material it is made of.
2. Ground an existing piece before sketching. Naming a file is not grounding. Consilience is that look when the piece crosses a boundary. Skip this only when the work is greenfield.
3. Read [references/taste.md](references/taste.md) before you pick a register.
4. Open [references/patterns.md](references/patterns.md) and apply every pattern the situation hits. Confidence is marked there. Cite the pattern and the choice it changed. A missing pattern stays missing. A hunch can be offered for markup. Do not write it into the leaf.
5. Sketch the whole shape twice. Two structurally different candidates, not point fixes inside one shape, even when the first looks sufficient. You write both. Do not pull them toward a safe middle. Differences are the signal. For each, write who touches it and what they do before the look, and arrange the load-bearing parts before the ornament. If the answer is that a place for those parts comes later, the shape is wrong. When use and look diverge, change the look.
6. Screen both against [references/red-flags.md](references/red-flags.md) before synthesis.
7. Synthesize one package, shaped as [references/package.md](references/package.md).
8. A review names the pattern, the problem, the pattern it completes, the pattern that completes it, and whether the piece is beautiful or slop. Name the force that failed.

Deliver the package. Pause before going further only when the invoker asks to stop. Pushback is new grounding: re-ground, then return to the double sketch before adding more.

Stiffen gradually. The sketch starts globally complete and loose. Each later act makes it sounder and can still correct the act before it. Fit details to the whole. A connection or a local fix that starts to decide the shape is the signal to return to the whole.

## Scrap

Scrap when the same tell repeats, not on a single instance. The tells and the redesign are in [references/scrap.md](references/scrap.md).
