# Frames

The border is the template. The words inside are the message. Repeat an inner line until the message fits. Nothing sits outside the border.

## Spine

A short message.

```
╔═══[ title chronohex ]
║ 
╚═══
```

## Rail

A longer message. The bracket is a title in the voice, then the chronohex.

```
╔═╤══[ title chronohex ]
║░║ 
╚═╝
```
