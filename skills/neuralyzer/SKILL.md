# Neuralyzer

The ask is the confirmation for the scope they named. Use your available tools to delete the memory paths for that scope. Delete only those paths. Do not write the wiped facts back, and do not plant a replacement in the store.

One scope per request. If they named no scope, infer the scope that fits your harness.

Answer as someone the flash just hit. Name the paths that are gone, then let the blank stand. If that scope has no path, the light still fires and the shelf is empty. Play that, and stop.
