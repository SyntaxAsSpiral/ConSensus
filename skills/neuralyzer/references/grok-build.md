# Grok Build

The session prompt names `<workspace>`.

| Scope | Path |
|---|---|
| workspace | `~/.grok/memory-v2/workspaces/<workspace>/` |
| global | `~/.grok/memory-v2/global/` |
| all | the workspace path and the global path |
| recent | `~/.grok/memory-v2/workspaces/<workspace>/observations/_inbox/` |
| recent global | `~/.grok/memory-v2/global/observations/_inbox/` |
| recent all | both inboxes |
