# Homes

Morphognome writes. Harmonion and Critikon do not. One fact, one home.

## Skill

A procedure, a missed trigger, or a fact a skill already owns. Edit that skill's vault source.

- A sentence or a stale fact: edit it in place.
- A buried rule: move it. Do not add a second copy.
- `tune description`: the skill should have fired and did not. Change the description that decides when it fires.
- `new skill`: no skill is a home, and the pattern has already recurred. The approved name, under `skills/`, with a recipe. Do not assemble.

A fleet bot does not write the vault. It hands the skill row to a coding agent. A coding agent running this command edits the vault source. Leave deployed copies and staging alone.

## Shared memory

A fact every bot should carry, and no skill owns it. The file the bots share is `/workspace/shared/MEMORY.md`.

A shared memory deleted in the operator's stead is the veto. It is not a Critikon pass. Do not write it back.

## Personal memory

A fact that is true for one bot and false for the others. Write only the memory that bot already reads. Do not write another bot's memory. If that file cannot be found, ELEVATE. Do not invent a path.

## Mechanism

A lint, a script, or a type could enforce it. Leave the row for archeoform. Do not add prose to a skill or a memory to cover it.

## Nowhere

A one-off, a fact that will rot with a path or a version, or a rule the home already states clearly. Write nothing.
