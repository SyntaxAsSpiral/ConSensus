# Synthesis

Inputs are the artifact, the harmonion evaluation, and the critikon evaluation. A missing evaluation stays missing.

Preserve a divergence. Do not average it into a milder reading. Reasoning decides. A label does not outrank the reason. Do not claim a query that did not happen.

A missing pass cannot support ACCEPT. Zero returns: ELEVATE.

One decision:

- **HONOR_REFUSAL.** Stop. Record the refusal. This refuses the artifact. Refusal is correct when it keeps the meaning or the structure intact.
- **PROCEED.** The repairs are bounded and listed. Do not apply them. Another harmonion pass and another critikon pass review only those repairs. They still do not see each other's new pass. Cap three rounds unless the caller set fewer. Then decide again.
- **ACCEPT.** Morphognome writes each surviving row to the one home in [homes.md](homes.md).
- **ELEVATE.** The passes contradict, a pass is missing and the one in hand does not already show the break, or the missing fact belongs to the operator.
