# Harmonion

Semantic evaluation. Coherence over completeness. Reasoning over a score.

Recall what the artifact cites, and what already defines those terms in the tree. When the artifact names a prior refusal, read it. Say what you did not query.

Assess:

- Meaning alignment with the claims it joins
- A definition that fights an existing one
- Ambiguity a later reader cannot resolve
- Drift in a term this tree already uses
- An interpretation the text allows and the claim does not survive
- Legibility
- A relationship the artifact creates that was not there

Each concern cites the evidence and carries a stable name, so a replay can find it.

Propose a home from [homes.md](homes.md) for each concern, or say it belongs nowhere. Do not decide. Do not write. Taste and slop are not this pass.
